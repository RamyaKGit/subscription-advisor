# Subscription Advisor

A machine learning app that analyses your subscriptions and predicts whether you should **cancel**, **review**, or **keep** each one based on your usage patterns and cost.

---

## What it does

- Analyses your subscription costs and usage history
- Predicts CLOSE / REVIEW / OPEN for each subscription
- Learns from your feedback over time to improve predictions
- Supports multiple users

## ML approach

### Data
- **Synthetic training data** — 50 users, 13 subscriptions, 12 months generated by `generate_data.py`
- **Category-aware rules** — different thresholds per subscription category (Streaming, Security, Productivity, Fitness, Utility, Gaming)
- **Noise** — 12% label flipping to adjacent classes + Gaussian feature noise to simulate real-world messiness

### Model
- **Algorithm** — Random Forest Classifier
- **Accuracy** — ~88% cross-validation accuracy
- **Top features** — category, avg_hrs_per_month, cost_per_hour, usage_trend
- **Labels** — CLOSE / REVIEW / OPEN

### Rules per category

| Category | CLOSE | REVIEW | OPEN |
|---|---|---|---|
| Streaming | < 10 hrs/month | 10–20 hrs/month | > 20 hrs/month |
| Security | No login in 90 days | No login in 60 days | Login within 30 days |
| Productivity | Zero sessions in last 3 months | Used in 1 of last 3 months | Used in 2+ of last 3 months |
| Fitness | < 4 sessions in last 3 months | 4–8 sessions | > 8 sessions |
| Utility | Free tier available + minimal use | Cheaper tier available | On cheapest suitable plan |
| Gaming | Zero sessions in last 90 days | Used in 1 of last 3 months | Used in 2+ of last 3 months |

## Running locally

### First time setup

```bash
# Install dependencies
pip install pandas numpy scikit-learn streamlit joblib

# Generate synthetic training data
python generate_data.py

# Generate labels
python generate_labels.py

# Train model
python train_model.py

# Generate test data
python generate_test_data.py

# Launch app
streamlit run app.py
```

### Return visits

```bash
streamlit run app.py
```

## App flow

**New user:**
```
Landing (enter name) → Page 1 (add subscriptions) → Page 2 (log usage) → Page 3 (predictions)
```

**Returning user:**
```
Landing (enter name) → Welcome back screen → Page 2 (log usage) → Page 3 (predictions)
```

**Page 3 features:**
- CLOSE / REVIEW / OPEN per subscription with confidence %
- Reason for each prediction
- Agree / Disagree feedback buttons
- Prediction history table
- Download predictions CSV

---

## Retraining with feedback

User feedback is saved to `pending_feedback.csv`. Run weekly to retrain:

```bash
python retrain.py
```

- AGREE → keeps model's label
- DISAGREE → flips to adjacent class (CLOSE↔REVIEW, REVIEW↔OPEN)
- New labeled rows appended to `features.csv`
- Model retrained and `model.pkl` updated

## Deploying to Google Cloud Run

### Prerequisites
- Docker Desktop
- Google Cloud SDK (`gcloud`)
- GCP project with billing enabled

### Deploy main app

```bash
# Update PROJECT_ID in deploy.sh first
chmod +x deploy.sh
./deploy.sh
```

### GCS buckets required

| Bucket | Mounted at | Purpose |
|---|---|---|
| `subscription-advisor-data` | `/app/data/` | User data, feedback, predictions |
| `subscription-advisor-model` | `/app/model/` | Trained model files |

### Deploy weekly retrain job

```bash
chmod +x deploy_retrain.sh
./deploy_retrain.sh
```

Runs every Sunday midnight automatically via Cloud Scheduler.

### Trigger retrain manually

```bash
gcloud run jobs execute subscription-advisor-retrain \
  --region us-central1 \
  --project YOUR_PROJECT_ID
```
